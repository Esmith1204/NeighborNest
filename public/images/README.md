# Photos

Drop free-license photos here with these exact file names (JPG, about 1600 px wide, under 400 KB each):

| File | Used for | Suggested subject |
|---|---|---|
| `hero.jpg` | Landing hero (circle mask) | A small backyard cottage / ADU |
| `neighborhood.jpg` | Full-bleed band under the hero | A residential street |
| `cottage.jpg` | Dark background behind the role grid | A detached backyard home |
| `homeowner.jpg` | Homeowner card | A backyard with room for a second home |
| `renter.jpg` | Renter card | The door or porch of a small home |
| `partner.jpg` | Partner card | A row of neighborhood homes |

Until a file exists the app shows a dark gradient, so nothing breaks.

Rules: free-license only (for example Unsplash or Pexels licence), no hotlinking, no scraping, no
photos of identifiable people or real addresses. Add the photographer, licence and page URL to
`credit` in `src/lib/images.ts`; the Sources page lists them.
